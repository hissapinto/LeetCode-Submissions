# LeetCode Solutions

Minhas soluções de problemas do [LeetCode](https://leetcode.com/), resolvidos como parte de um estudo contínuo de **estruturas de dados e algoritmos**. O foco não é acumular quantidade, mas praticar o **reconhecimento de padrões** — identificar, a partir do enunciado, qual técnica resolve o problema.

A maioria das soluções está em **Java**, com algumas em **C**.

## Objetivo

Este repositório acompanha meu progresso no estudo de algoritmos, seguindo uma trilha organizada por **padrões** (arrays & hashing, two pointers, sliding window, binary search, árvores, grafos, backtracking, programação dinâmica, entre outros) em vez de resolver questões soltas. A ideia é construir a intuição de reconhecer o padrão por trás de cada problema — a habilidade que realmente importa em entrevistas técnicas.

Para cada questão, procuro:
1. Tentar a solução por conta própria antes de consultar qualquer referência;
2. Escrever a abordagem em uma frase ("isto é *two pointers* porque...");
3. Analisar a complexidade de tempo e espaço.

## Organização

Cada questão fica em sua própria pasta, nomeada pelo problema (ex.: `TwoSum/`, `ContainerWithMostWater/`, `ThreeSum/`). Dentro de cada pasta está a solução na linguagem correspondente (`.java` ou `.c`). Algumas soluções incluem, além da versão final, uma versão inicial (*naive*) e a otimizada, com comentários sobre a análise de complexidade e as melhorias aplicadas.
